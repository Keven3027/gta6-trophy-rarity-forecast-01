Forecasts every GTA VI (PS5) trophy's earn rate on Exophase at a target instant, as five quantiles per trophy, scored by pinball loss on the logit scale. The model decomposes each rate into tracked players (a damped-drift extrapolation of the denominator's explosive launch growth) and earner counts (per-trophy elasticity of earner growth to tracked growth, from the launch-night completionist front-load to the mainstream story wave), with the spread from an internal backtest of the case's own history. Node 22, standard library only, deterministic.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
